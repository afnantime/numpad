# Numpad Desktop สำหรับ Windows 10

โปรแกรมสลับ Windows Virtual Desktop ด้วย Numpad รองรับ Windows 10 รุ่น 1809–22H2
ใช้ .NET Framework 4.x ที่มีใน Windows 10 ไม่ต้องติดตั้ง AutoHotkey

## เปิดใช้งาน

1. เปิด `dist\NumpadDesktop.exe` โดยเก็บ `VirtualDesktop.dll` ไว้ในโฟลเดอร์เดียวกัน
   หรือแตกไฟล์ `dist\NumpadDesktop-Windows10.zip` แล้วเปิด EXE ในโฟลเดอร์ที่แตกไฟล์
2. ครั้งแรกจะมีหน้าตั้งค่าปุ่ม กด **ตรวจจับ** ทีละช่อง แล้วกดปุ่มจริง:
   - ช่อง 1: `(` บน Numpad เพื่อเข้าโหมด 1
   - ช่อง 2: `)` บน Numpad เพื่อเข้าโหมด 2
   - ช่อง 3 และ 4: พิมพ์ `(` และ `)` จากแถวบนตามปกติ ใช้ภาษาอังกฤษตอนตรวจจับ
3. กด **บันทึก** โปรแกรมเริ่มในโหมด 2 เสมอ
4. กด `(` เพื่อเข้าโหมด 1 จากนั้นกด Numpad 1–9 เพื่อไป Desktop ตามหมายเลข
   เช่น กด 5 แล้วถ้ามีเพียง 2 Desktop จะสร้างเพิ่มจนครบ 5 แล้วไป Desktop 5
5. กด `)` เพื่อกลับโหมด 2 Numpad จะทำงานตามสถานะ Num Lock เดิม

ในโหมด 1 ใช้ตำแหน่งปุ่ม Numpad 1–9 ได้แม้ปิด Num Lock และเลขจะไม่เข้าแอป
การกดค้างไม่สั่งซ้ำ เลขแถวบนยังพิมพ์ได้ ส่วน Ctrl/Alt/Win ร่วมกับ Numpad
ยังส่งให้แอปตามปกติ ปุ่ม 0 จุดทศนิยม Enter และเครื่องหมายคำนวณไม่เปลี่ยน
เว้นแต่เลือกปุ่มนั้นเป็นปุ่มเปลี่ยนโหมด

## ถ้าปุ่มวงเล็บซ้ำกับแถวบน

Numpad บางรุ่นส่งปุ่มวงเล็บเป็น Shift+9 / Shift+0 เหมือนแถวบนทุกประการ
keyboard hook จะแยกตำแหน่งหรืออุปกรณ์ต้นทางไม่ได้ในกรณีนี้ โปรแกรมจะไม่ยอม
บันทึกการผูกปุ่มที่ซ้ำกัน ให้ตรวจจับช่อง 1 และ 2 ใหม่โดยใช้ปุ่มอื่น เช่น
Numpad `/` และ `*` ส่วนช่อง 3 และ 4 ยังคงเป็นวงเล็บแถวบน
สามารถเปลี่ยนโหมดผ่านเมนูไอคอนข้างนาฬิกาได้แม้ยังไม่ได้ผูกปุ่ม

การตรวจจับบันทึก VK, scan code, extended flag และ modifier ไม่ใช่ข้อความ
ใช้รูปแบบปุ่มและ modifier เดิมตอนใช้งาน หากเปลี่ยน keyboard layout หรือคีย์บอร์ด
ให้ตรวจจับใหม่ ไม่รองรับปุ่มที่ส่งข้อความ Unicode หรือ macro หลายปุ่มซับซ้อน
และไม่แยกคีย์บอร์ดสองตัวที่ส่งรหัสปุ่มเหมือนกัน

## เมนูและการตั้งค่า

- ไอคอนเลข **1** สีฟ้า = โหมดสลับ Desktop; เลข **2** สีเขียว = โหมดปกติ
- คลิกขวาที่ไอคอนเพื่อเปลี่ยนโหมด ตั้งค่าปุ่ม เปิดพร้อม Windows หรือออก
- ดับเบิลคลิกเพื่อเปิดหน้าตั้งค่า ถ้าไม่เห็นไอคอนให้ดูปุ่มลูกศรข้างนาฬิกา
- เปิดพร้อม Windows ปิดไว้เป็นค่าเริ่มต้น เลือกเองในเมนูแล้วจะบันทึกใน Registry
  ของผู้ใช้ปัจจุบัน หากย้ายโฟลเดอร์ ให้ปิดและเปิดตัวเลือกนี้อีกครั้ง
- ตั้งค่าอยู่ที่ `%LOCALAPPDATA%\NumpadDesktop\settings.json`
- เมื่อจัดการ Desktop ผิดพลาด จะกลับโหมด 2 และแจ้งสาเหตุ พร้อมเก็บ `errors.log`
- หมายเลข Desktop อิงลำดับปัจจุบันใน Task View ไม่ใช่ชื่อ Desktop
- ออกจากโปรแกรมแล้วคีย์บอร์ดกลับปกติ Desktop ที่สร้างไว้ยังคงอยู่

## Build และทดสอบ

จาก PowerShell ในโฟลเดอร์ซอร์ส:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\dist\NumpadDesktop.Tests.exe
.\dist\NumpadDesktop.Tests.exe --desktop-integration
```

build ใช้ compiler `C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe`
โดยไม่ต้องใช้ .NET SDK และตรวจ checksum ของ upstream ก่อน compile

**การทดสอบ integration จะสลับ Desktop ชั่วคราว**: สร้างเพิ่มถึง 9 ถ้าจำเป็น
ทดสอบ Desktop 1, 5, 9 แล้วกลับ Desktop เดิม และลบเฉพาะ Desktop ที่การทดสอบสร้าง
อย่าจัดการ Desktop หรือย้ายหน้าต่างระหว่างทดสอบ

`NumpadDesktop.exe --smoke` เปิด tray และ hook 1.5 วินาทีแล้วปิดเอง
โดยไม่แสดงหน้าตั้งค่าหรือแก้ค่าผู้ใช้

การทดสอบด้วยคีย์บอร์ดจริงยังจำเป็น: ปุ่มวงเล็บของ Numpad แต่ละรุ่นอาจส่งรหัสต่างกัน
ตรวจทั้ง Num Lock เปิด/ปิด การกดค้าง การพิมพ์วงเล็บแถวบน และการกลับโหมด 2
แอปที่ Run as administrator อาจต้องให้โปรแกรมนี้ทำงานด้วยสิทธิ์เดียวกัน
ไม่ควบคุมหน้าจอ UAC, lock screen หรือ secure desktop
